## Hola, soy Patricio Villarroel

Diseño y construyo productos digitales desde hace más de veinte años. Vengo del diseño gráfico y de interfaces, pasé por desarrollo, calidad y liderazgo de producto, y hoy estoy especializándome en arquitectura cloud sobre AWS.

Lo que me interesa es la parte del trabajo donde una decisión técnica tiene consecuencias de negocio: qué servicio elegir, cuánto cuesta sostenerlo y qué se rompe cuando crece. Diseño lo que puedo construir y estimo lo que diseño.

**Trabajando en:** arquitecturas cloud sobre AWS, automatización con IA aplicada, productos web con Astro y Supabase.

**Herramientas:** AWS (ECS, Fargate, Lambda, API Gateway, RDS, DynamoDB, S3, CloudFront, CloudWatch) · Docker · Node.js · Python · JavaScript · SQL · Astro · n8n · Figma
